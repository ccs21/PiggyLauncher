# 공개본에서 바꾼 부분과 이어 읽을 예제

원본 Classic과 공개본은 목적이 다르다. 게임 실행·종료 감시와 데이터 처리의 핵심 흐름은 보존하고, 계정·광고·외부 운영 의존성과 학습에 불필요한 출력은 정리했다. 모든 플랫폼 실게임 동작을 재검증한 버전은 아니다.

| 정리한 부분 | 공개본 처리 | 교재·예제 |
|---|---|---|
| 고정 자격 증명과 암호화 키 | 운영 자격 증명을 포함하는 파일 제외 | scraper_credentials.py, wiki/API_SETUP.md |
| 회원 인증 | 런처에서 제거, 로컬 사용에 로그인 불필요 | examples/lab_server.py, oauth_desktop.py |
| 프리미엄 | 판정 변수·제한 분기·잠금 화면 제거 | 배치 설정·게임 수정·프리셋·카테고리 코드에서 직접 흐름 읽기 |
| 광고·후원 | 실행·표시·설정·링크 제거 | 별도 결제/광고 예제 제공 안 함 |
| 외부 장치 보고 | 자동 전송 제거 | examples/smtp_optional.py의 명시적 전송 실습 |
| 공지 수신 | 시작 시 운영 공지를 조회하지 않음, 로컬 알림 큐 보존 | examples/lab_client.py의 순서·중복 제거 |
| 자동 업데이트 | 자동 다운로드·프로그램 교체 제거, 안내 화면으로 변경 | examples/release_client.py의 조회·해시 검증 |
| 상품 매핑 서버 | 빈 설정이면 통신 안 함 | service_settings.py, 가상 매핑 JSON |
| 개인정보 로그 | 원본 print 디버그 출력 제거, 빈 오류 처리 일부를 예외 종류 로그로 변경 | 요청 URL·토큰·본문을 기록하지 않는 방식 비교 |
| import 부작용 | 로그 파일 생성·전역 예외 처리 패치 제거 | main.py의 실행 진입점과 bootstrap.py |
| 리소스 | 개인 라이브러리·기존 아트워크·폰트·외부 EXE 제외 | 새로 만든 중립 SVG와 스타일 설정 |
| 코드 형식 | 파싱 기반 정리, 중복/미사용 import 제거, 일관된 포맷 | docs/SOURCE_MAP.md |

## 그대로 남겨 설명할 한계

- 일부 UI 작업과 수집 작업은 긴 함수에 결합되어 있다. 단순히 함수를 잘게 나누는 것보다 상태와 스레드 경계를 파악하고 분리하는 실습에 적합하다.
- 웹사이트의 DOM과 브라우저 세션에 의존한 수집기는 사이트 변경에 취약하다.
- 현재 공개본의 Epic/STOVE 자동 매칭은 자신이 준비한 매핑 자료가 필요하다.
- 게임 종료 관찰에는 프로세스·창·대기 조건이 사용된다. 모든 게임에 보편적인 판정이라고 가정하지 않는다.
- 외부 실행 파일을 사용하는 해상도 변경·VDF 파싱은 해당 도구를 별도로 준비해야 한다.
- 일부 예외 처리는 복구 방법보다 작업 중단·건너뛰기에 집중되어 있다. 추가 실습에서는 실패를 화면에 어떻게 전달할지 설계한다.
- 라이브 서비스의 실계정 인증, 플랫폼별 실게임 실행, 모든 해상도와 입력 장치 조합은 이번 공개 소스 검사 범위에 포함하지 않는다.
