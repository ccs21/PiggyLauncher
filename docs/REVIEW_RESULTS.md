# 공개용 소스 검사 결과

검사일: 2026-10-09. 이 문서는 공개 준비본의 검사 범위를 설명한다. 전체 제품의 무결성이나 실서비스 호환성을 보증하는 문서가 아니다.

## 조사 및 정리 범위

- 원본의 실행 후보 Python 파일 90개를 목록화하고 main.py의 정적 의존성과 별도 실행 경로를 검토했다.
- 원본에서 선별한 51개 모듈을 정리해 옮겼다. 안내 화면 3개는 공개본에 맞게 다시 작성했고, 설정·초기화 경계 모듈 3개를 추가했다.
- 독립 교재 예제 7개와 테스트 파일 4개를 포함해 공개 대상 Python 파일은 68개다.
- 백업·관리 도구·서버 소스·운영 설정·브라우저 프로필·개인 게임 목록은 복사하지 않았다.
- 비밀정보를 직접 포함하는 인증·외부 보고 코드는 제외하고 빈 API 설정 또는 독립 예제로 대체했다.
- 광고·후원·회원 등급 판정·잠금 UI·공식 바이너리 자동 교체를 제거했다.
- 미사용 import와 지역 변수, 동일한 스크래핑 분기, 중복 설정 쓰기 및 중복 사전 키를 정리했다. 게임별 실행·종료 기준을 새 정책으로 바꾸지는 않았다.
- 기존 디버그 출력은 제거하고 오류 종류만 남기는 로깅으로 일부 보완했다. 원본의 오래된 주석을 그대로 복사하지 않고 모듈 설명·학습 문서·사례 설명으로 정리했다.

## 통과한 검증

1. 공개 대상 Python 전체 구문 검사.
2. Ruff F 규칙 검사: 미정의 이름·미사용 import/변수·중복 키 등 검사.
3. 공개 루트 모듈 전체 import: 임시 작업 폴더, 네트워크 연결·외부 프로세스 실행 차단.
4. 새 가상환경 자동 테스트 27개: 빈 키, 환경변수 우선 적용, 사용자 암호 미저장, 기존 설정 보존, 미설정 서버 통신 방지, 가상 로그인/세션 만료/공지 중복 제거, 해시 비교/OAuth state, 주요 UI 생성. 하나의 테스트가 여러 관련 조건을 확인한다.
5. 주요 UI: 빈 라이브러리에서 메인·설정·ROM 수집·배치·업데이트 안내를 오프스크린으로 생성/종료. 실제 패드 처리는 대체했고 게임은 실행하지 않았다.
6. 공개 대상 텍스트 전체에서 기존 비밀값 일치, 운영 식별자, 대표 토큰/개인키 패턴을 비공개 검사 도구로 대조. 비밀값 자체와 금지 주소 목록은 교재에 포함하지 않는다.
7. 원본 Python 파일 90개의 SHA-256이 조사 시작 시점과 동일함을 확인.

## 이번 마무리에서 추가 확인한 내용

- Windows / Python 3.10.11의 시스템 패키지를 공유하지 않는 새 venv에 requirements.txt 설치 성공. pip check 통과. 설치 버전 전체를 requirements-lock.txt에 기록했다.
- 한글 requirements의 Windows 인코딩 문제를 수정했다. 알림음은 winsound로 바꾸어 simpleaudio 빌드 의존성을 없앴다.
- 테마의 transparent·글꼴 이름을 파일 경로로 잘못 바꾸던 부분을 수정하고 회귀 테스트를 추가했다.
- 별도 임시 폴더에 공개 파일만 복사하여 main.py 시작 진입점에서 메인 창 생성까지 확인했다. Qt offscreen에서는 유효한 Windows 창 핸들이 없으므로 모니터 정보 호출만 실제 주 모니터의 읽기 결과로 대체했다. 패드 수는 0으로 대체하고 네트워크·외부 프로세스 실행은 차단했다.
- SQLite 공지 페이지·백업, 영속 큐의 재시작·중복 제거, 실제 루프백 HTTP 페이지 조회·로그아웃 테스트를 추가했다.
- 자체 MIT LICENSE, 의존성·별도 도구 고지를 확정했다. 외부 바이너리·원본 아트워크는 포함하지 않는다.
- 위키 6개 장에 명령·예상 결과·장애 실험과 확장 경계를 작성했다.

## 검증 범위 밖과 학습 과제

- EXE 빌드 및 외부 실행 파일·라이브 플랫폼·실게임·실제 패드 전체 조합 검증. 이번 결과물은 실행 파일 배포가 아닌 교육용 소스다.
- OAuth 예제는 PKCE/state와 토큰 교환 함수다. 브라우저 콜백·ID 토큰 검증·운영 세션 저장은 교재의 확장 절차를 따라 별도로 구현해야 한다.
- HTTPS·외부 배포는 설계와 설정 예시를 제공한다. 실제 공개 서버를 개설하거나 운영 서비스에 연결하지 않았다.
- 공지 실습 큐는 단일 프로세스 기준이다. 표시 직후 확인 저장 전 장애에는 중복 표시가 가능하다. 정확히 한 번 표시를 보장한다고 설명하지 않는다.
- 코드 정리는 원래 구조를 보존하는 범위다. 남은 긴 함수·넓은 예외 처리·동기 UI 작업은 사례 문서의 학습 과제다.

GitHub 저장소와 위키에는 게시하지 않았다. 이 결과는 비밀정보가 절대 존재할 수 없다는 보장이 아니라, 명시한 검사와 범위에서 발견 사항을 정리한 결과다.
