# 서버와 API 학습 교재

가상의 Launcher Lab을 새로 만드는 독립 교재다. 운영 중인 제품의 서버 코드·주소·DB·인증값·로그를 사용하지 않는다. 로그인 없이도 공개 런처의 로컬 기능을 사용할 수 있다.

## 읽는 순서

1. [환경과 HTTP](01-환경과-HTTP.md): 두 터미널에서 서버·클라이언트 실행, 성공·실패 응답.
2. [로그인과 세션](02-로그인과-세션.md): 발급·만료·로그아웃, 자신의 OAuth 앱으로 확장하는 절차.
3. [공지와 큐](03-공지와-큐.md): SQLite 저장, 페이지 조회, 재시작해도 남는 수신 큐.
4. [업데이트 API](04-업데이트-API.md): 자신의 GitHub 릴리즈 조회, 버전·자산 선택, 무결성 검증.
5. [Qt와 연결](05-Qt와-연결.md): UI 스레드 경계, 취소, 오프라인·복귀 처리.
6. [백업과 운영](06-백업과-운영.md): 실제 SQLite 백업·복원 실습, HTTPS와 배포 설계.

[외부 API 키 설정](API_SETUP.md) · [예제 실행 안내](../examples/README.md) · [전체 학습 길잡이](../docs/LEARNING_GUIDE.md)

## 구현 범위

로컬 암호 세션, 로그아웃, 공지 작성 CLI, SQLite 저장·백업, 페이지 조회와 클라이언트 영속 큐는 실행 가능한 예제다. Google OAuth는 PKCE/state·코드 교환 함수와 확장 절차를 제공한다. 완성된 Google 로그인 서비스, 공개 웹 관리자, 설치기 및 운영 서버는 포함하지 않는다.

실습 API는 독립 규약이다. 실제 Qt 알림 연결은 5장의 확장 과제이며 공개 런처가 실습 서버에 자동 접속하지 않는다. 기본 주소는 루프백이고 HTTPS 설명에는 예약 예시 도메인을 사용한다.
